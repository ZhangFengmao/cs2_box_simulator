# cs2_box_simulator

一个纯前端、本地运行的 CS2 风格开箱模拟器。项目内置反冲、梦魇、变革、热潮四种武器箱和古堡激战纪念包，支持选择容器、滚动开箱、稀有物品揭晓，以及浏览器本地武器仓库。

## 主要功能

- 四种武器箱及对应钥匙，以及无需钥匙的古堡激战纪念包
- 6.2 秒拟真减速滚动和品质展示效果
- 支持勾选“跳过动画”直接查看抽取结果
- 金色奖励抽中后才揭晓具体刀具或手套
- 普通钥匙箱演示概率：蓝 66.62%、紫 15.98%、粉 12.80%、红 3.06%、金 1.54%
- 古堡激战纪念包的隐秘级（AWP｜巨龙传说）概率为 3%，消费级为 77.032%
- 抽中物品自动保存到浏览器本地仓库
- 武器仓库支持品质筛选及高低品质排序

## 依赖

- Python 3：启动静态 Web 服务
- Node.js / npm：可选，仅用于执行 npm 启动命令
- 现代浏览器：Chrome、Edge、Safari 或 Firefox

无需安装 npm 包，也不依赖 NoneBot 或任何 Python 第三方库。

## 启动

在项目目录中执行：

```bash
npm run start
```

未安装 Node.js 时，可直接执行：

```bash
python3 -m http.server 8080 --bind 0.0.0.0
```

启动后访问：

- 本机：`http://localhost:8080`
- 局域网：`http://你的电脑局域网IP:8080`

局域网设备需与电脑处于同一网络，且系统防火墙允许 Python 接收传入连接。

## 本地数据

箱子、钥匙和抽中的物品保存在浏览器 `localStorage` 中。清除该站点的浏览器数据会重置仓库。

第三方素材与许可说明见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。本项目仅用于本地交互演示，与 Valve 或 Counter-Strike 2 官方无关。

如需重新同步本地物品图片，可执行 `python3 scripts/update_game_assets.py`。该维护脚本需要联网，正常运行项目不需要联网。
